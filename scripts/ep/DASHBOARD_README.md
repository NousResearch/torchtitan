# 🌐 Interactive Web Dashboard for EP Performance Analysis

## Overview

The Gradio dashboard provides an interactive web interface for viewing and analyzing EP performance results, accessible via a public URL from your local machine when connected through SSH.

## Quick Start

```bash
# Launch the dashboard
./scripts/ep/START_DASHBOARD.sh
```

After ~10 seconds, you'll see output like:
```
Running on local URL:  http://0.0.0.0:7860
Running on public URL: https://xxxxx.gradio.live
```

**Copy the public URL** (https://xxxxx.gradio.live) and open it in your local browser!

## Features

The dashboard includes 6 tabs:

### 1. 📊 Quick Start
- Quick reference guide
- Key commands
- Overview of findings

### 2. 📈 Box Plot - Distribution
- Interactive box plots showing distribution of operation times
- Compare EP=2 vs EP=1 side-by-side
- Shows min, max, median, mean, and quartiles
- Identify operations with high variability

### 3. 📊 Waterfall - Contribution
- Waterfall chart showing cumulative contribution to slowdown
- Each bar represents one operation's impact
- Percentages show relative contribution
- Helps prioritize optimization targets

### 4. 🔀 Rank Comparison
- Bar chart comparing performance across all ranks
- Identifies if specific ranks are slower
- Useful for debugging load imbalance

### 5. 📋 Full Report
- Complete technical analysis
- Root cause identification
- Proposed solutions
- Implementation details

### 6. 📚 Advanced Analysis
- Documentation on advanced features
- Averaging methodology
- Contribution analysis explained
- Statistical details

## Requirements

- **Gradio**: Automatically installed if not present
- **Plotly**: For interactive visualizations (auto-installed with advanced_analysis.py)
- **Analysis data**: Run profiling first if plots are missing:
  ```bash
  ./scripts/ep/run_profiling.sh both
  env/bin/python scripts/ep/advanced_analysis.py
  ```

## Usage

### Standard Launch

```bash
./scripts/ep/START_DASHBOARD.sh
```

The dashboard will:
1. Check if Gradio is installed (install if needed)
2. Start the web server on port 7860
3. Create a public tunnel via Gradio
4. Display the public URL

### Manual Launch

```bash
env/bin/python scripts/ep/simple_dashboard.py
```

### Stopping the Dashboard

Press `Ctrl+C` in the terminal where the dashboard is running.

Or kill the process:
```bash
pkill -f "simple_dashboard.py"
```

## Files Generated

When you run advanced analysis, these files are created in `scripts/ep/`:

- `boxplot.html` - Interactive box plot (4-5 MB)
- `waterfall.html` - Contribution waterfall chart (4-5 MB)
- `rank_comparison.html` - Rank comparison plot (4-5 MB)

The dashboard automatically loads and displays these files.

## Troubleshooting

### "Plot not available" message

Run the advanced analysis first:
```bash
env/bin/python scripts/ep/advanced_analysis.py
```

### "Missing trace data" error

Run profiling:
```bash
./scripts/ep/run_profiling.sh both
```

### Port 7860 already in use

Kill existing processes:
```bash
pkill -f "simple_dashboard.py"
# Wait a few seconds
./scripts/ep/START_DASHBOARD.sh
```

### Can't access public URL

- Make sure you're copying the full URL including `https://`
- The URL is valid for 72 hours
- If it expires, restart the dashboard to get a new URL

### Dashboard loads but plots are huge/slow

The HTML plot files are 4-5 MB each because they contain interactive Plotly visualizations with all the data embedded. This is normal. They load once and then are fully interactive in your browser.

## Architecture

The dashboard consists of:

1. **simple_dashboard.py** - Main Gradio application
   - Loads pre-generated HTML plots
   - Displays markdown documentation
   - Provides tabbed interface

2. **advanced_analysis.py** - Analysis engine (optional dependency)
   - Generates interactive Plotly visualizations
   - Computes statistics and contributions
   - Creates HTML files

3. **START_DASHBOARD.sh** - Launch script
   - Handles environment setup
   - Starts dashboard with proper configuration

## Self-Contained Design

All dashboard files are contained in `scripts/ep/`:
- Dashboard code: `simple_dashboard.py`
- Launch script: `START_DASHBOARD.sh`
- Generated plots: `*.html`
- Documentation: `*.md`, `*.txt`

No files are created outside of `scripts/ep/` directory.

## Public URL Security

The Gradio public URL:
- Is randomly generated and hard to guess
- Expires after 72 hours
- Can be regenerated by restarting the dashboard
- Should not be shared publicly if data is sensitive

## Performance Notes

- Initial load may take 5-10 seconds (loading large plot files)
- Once loaded, interactions are instant (client-side JavaScript)
- Dashboard uses minimal server resources (just serving static content)

## Alternative: Local Port Forwarding

If you prefer not to use the public URL, you can use SSH port forwarding:

```bash
# On your local machine
ssh -L 7860:localhost:7860 user@remote-server

# Then access in browser:
http://localhost:7860
```

## Integration with Analysis Tools

The dashboard complements the command-line tools:

- **CLI**: Best for quick checks and automation
  ```bash
  ./scripts/ep/compare_profiles.sh
  ```

- **Dashboard**: Best for exploring visualizations and detailed analysis
  ```bash
  ./scripts/ep/START_DASHBOARD.sh
  ```

Both tools work with the same underlying profiling data and analysis results.
