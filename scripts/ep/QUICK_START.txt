    ✗ EP=2 is 35% SLOWER than EP=1 (5,900 vs 7,961 TPS)

    Root Cause: Synchronous device-to-host memory transfers
    Location: torchtitan/distributed/expert_parallel.py:104

    Top Bottlenecks:
    • aten::_to_copy:      +2,314ms (+837%)  ← Main culprit
    • cudaMemcpyAsync:      +781ms (+1,350%)
    • nccl:all_to_all:    +1,115ms (new)

┌───────────────────────────────────────────────────────────────────────────┐
│ PROPOSED FIX                                                              │
└───────────────────────────────────────────────────────────────────────────┘

    File: torchtitan/distributed/expert_parallel.py
    Line: 104

    Change from:
        .to(torch.device("cpu"), non_blocking=False)

    To:
        .to(torch.device("cpu"), non_blocking=True)

    Expected improvement: 20-30% throughput increase
